# TimeEvolutionPEPO.jl

> **_NOTE:_** This package is in the pre-alpha stage, as such no basic functionality should be assumed.

A Julia package implementing algorithms for the simulation of driven-dissipative many-body quantum physics in two-dimensions. Based on [TensorKit.jl](https://github.com/Jutho/TensorKit.jl) package, and inspired by the [MPSKit.jl](https://github.com/maartenvd/MPSKit.jl) project.
