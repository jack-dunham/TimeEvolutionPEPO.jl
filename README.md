# PEPOKit.jl

> **_NOTE:_** This package is in the pre-alpha stage, as such no basic functionality should be assumed.

A Julia package implenting algorithms for the simulation of driven-dissipative many-body quantum physics in two-dimensions. Based on the excellent [TensorKit.jl](https://github.com/Jutho/TensorKit.jl)
package, and inspired by the [MPSKit.jl](https://github.com/maartenvd/MPSKit.jl) project.
