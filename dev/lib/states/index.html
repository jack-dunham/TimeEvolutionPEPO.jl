Type hierarchy

PEPO states

PEPOKit.AbstractPEPO — Type
abstract type AbstractPEPO{S<:IndexSpace} <: AbstractArray{S,2} end

Abstract supertype of all PEPO-like objects, i.e. networks of PEPOTensor types.

source
PEPOKit.PEPOTensor — Type
struct PEPOTensor{S<:IndexSpace} <: AbstractTensorMap{S,3,3}

Concrete type containing an AbstractTensorMap{S,3,3} with unit norm. By convention, the codomain is ordered (1,2,out) and the domain is ordered (3,4,in).

source
PEPOKit.FinitePEPO — Type
struct FinitePEPO{S<:IndexSpace} <: AbstractPEPO{S}

Concrete subtype of AbstractPEPO for representing finite sized square lattices of single-site PEPO tensors.

source
PEPOKit.InfinitePEPO — Type
struct InfinitePEPO{S<:IndexSpace} <: AbstractPEPO{S}

Concrete subtype of AbstractPEPO for representing infinite sized square lattices constructed by tessellating a single unit-cell.

source

Vectorised PEPO states

PEPOKit.VectorPEPOTensor — Type
struct VectorPEPOTensor{S<:EuclideanSpace} <: AbstractTensorMap{S,3,2}

Represents a vectorised PEPO state. The tensor field gives the TensorMap representing the state, and the unitary field gives the unitary who's inverse unvectorises the PEPO.
